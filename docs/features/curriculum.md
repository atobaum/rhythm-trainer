# 커리큘럼·자유 연습

## 1. 배경

배경은 [[design#1. 배경]]과 같다. 리듬 개념은 4분음표 → 8분음표 → 16분음표처럼 순서대로 쌓인다. 한 음형을 여러 패턴 속에서 반복해야 외우지 않고 익힌다. 반대로 특정 패턴만 골라 연습하고 싶을 때도 있다.

처음 구현은 단계마다 고정 패턴 4개를 두었다. 써 보니 몇 번 하면 패턴을 외워서 악보를 보지 않고 치게 되고, 새 음형만 따로 익히는 순서도 없었다. 그래서 단계를 새 음형 도입과 매번 새로 만드는 마디 흐름으로 바꾼다.

## 2. 목표

- 사용자는 음형별 단계 목록에서 진도를 보고 단계를 골라 진행할 수 있다.
- 사용자는 새 음형을 처음 배우는 단계에서 그 음형만 따로 친 뒤 아는 음형과 섞어 친다.
- 사용자는 단계를 할 때마다 처음 보는 마디를 받아서 악보를 보고 친다. 같은 단계를 다시 해도 같은 마디 순서가 나오지 않는다.
- 사용자는 두 마디씩 치고, 지금 칠 두 마디 아래에 다음 두 마디를 미리 보고 읽어 둘 수 있다.
- 단계를 깬 기록과 그때 BPM 이 저장되고 새로고침 후에도 남는다. 다음에 열면 깨지 않은 첫 단계가 선택돼 있다.
- 사용자는 고정 패턴, 기타 스트로크, 양손, 폴리리듬 목록에서 하나를 골라 바로 연습할 수 있다.

## 3. 비목표

- 사용자가 만드는 커리큘럼이나 패턴 편집기
- 서버 동기화. 기록은 그 기기에만
- 단계 안에서 같은 마디 순서를 다시 내 주는 기능. 다시 하면 늘 새로 만든다.

### 실패로 볼 것

- 같은 문제만 외워서 단계를 통과한다.
- 다음 단계가 이유 없이 잠겨서 진행이 막힌다.
- 다음 마디가 바뀌는 순간에야 보여서 미리 읽을 수 없다.
- 틀린 마디를 다시 칠지 다음으로 넘어갈지가 마디가 시작된 뒤에야 정해져서 무엇을 칠지 헷갈린다.

## 4. 사용자 흐름

### 단계

1. 연습 탭에서 "단계" 를 고른다. 목록은 깨지 않은 첫 단계 위치로 스크롤돼 있다.
2. 단계 카드에는 번호, 제목, 마디 수, 핵심 음형 아이콘, 통과 여부가 보인다.
3. 시작하면 그 단계의 마디들을 미리 만들고 두 마디씩 묶는다. 카운트인 한 마디 뒤 첫 두 마디부터 끊지 않고 친다.
4. 화면 위에는 지금 칠 두 마디, 아래에는 다음에 칠 두 마디가 흐리게 보인다.
5. 처음 친 두 마디가 깔끔하면 바로 다음 두 마디로 넘어간다. 틀리면 같은 두 마디를 바로 다시 치고, 한 번이라도 틀린 두 마디는 2번 연속 깔끔해야 넘어간다. 다음 자리에는 "다시" 또는 "한 번 더" 와 같은 두 마디가 보인다.
6. 마지막 두 마디까지 통과하면 단계를 깬 것으로 저장하고, 요약 화면에서 두 마디별 시도 횟수를 보고 다음 단계로 간다.

### 자유 연습

1. 연습 탭에서 "고정 패턴", "기타 스트로크", "양손", "폴리리듬" 중 하나를 고른다.
2. 목록에서 패턴을 고르고 시작한다. 처음에 바로 깔끔하게 치면 통과, 한 번이라도 틀렸으면 2번 연속 깔끔하게 쳐야 통과하고 목록의 다음 패턴으로 갈 수 있다.

## 5. 기능 정의

### 단계 구성

- 음형 26개를 배우는 순서로 둔다(4분쉼표, 8분음표, 당김음, 점4분음표, 3연음과 쉬는 3연음, 4분음표 3연음, 16분음표 조합, 점8분음표, 붙임줄, 16분 당김음 등). 3연음은 박을 셋으로 나누기만 하면 되어서 박을 넷으로 나누는 16분음표보다 먼저 둔다.
- 음형마다 1~4부 단계를 둔다. 부가 올라갈수록 한 마디에 넣는 새 음형 수가 는다.
- 섹션 끝마다 "여러 그림" 복습 단계를 둔다. 그때까지 배운 음형을 섞고 4/4 와 3/4 를 번갈아 쓴다.
- 16분음표 섹션 뒤에 둘로 나눔과 셋으로 나눔을 한 마디에서 바꿔 치는 "나눔 바꾸기" 섹션을 둔다(아래 절).
- 모두 114단계다.

### 단계의 마디

| 단계 | 도입 마디 | 생성 마디 | 마디당 새 음형 |
|---|---|---|---|
| 음형 1부 | 2 | 8 | 1 |
| 음형 2부 | 없음 | 8 | 2 |
| 음형 3부 | 없음 | 8 | 3 |
| 음형 4부 | 없음 | 8 | 4 |
| 복습 1~5부 | 없음 | 8 | 2, 2, 3, 3, 4 |

- 생성 마디 8개는 두도막(4마디 도막 2개) 길이다.
- 연습 단위는 두 마디다. 도입 2마디가 첫 단위이고, 생성 마디는 순서대로 둘씩 묶는다.
- 도입 마디는 음형마다 같은 규칙으로 만든다. 첫 마디는 앞 절반을 새 음형으로, 뒤 절반을 4분음표로 채운다. 둘째 마디는 4분음표와 새 음형을 번갈아 둔다. 2박짜리 음형은 박 단위 대신 2박 단위로 번갈아 둔다.
  - 예) 8분음표 2개 1부의 도입은 "8분 8분 8분 8분 4분 4분", 그다음 "4분 8분 8분 4분 8분 8분".
- 생성 마디는 단계를 시작할 때마다 새 시드로 만든다. 새 음형을 정한 개수만큼 무작위 위치에 넣고, 남는 박은 앞에서 배운 음형으로 채운다. 4분음표와 8분음표 2개를 더 자주 고른다. 한 마디에 들어가지 않는 개수는 들어가는 만큼만 넣는다.
- 4/4 에서 2박짜리 음형은 1박이나 3박에서만 시작한다. 그래서 2박 음형은 한 마디에 2개까지 들어간다.
- 바로 앞 마디와 똑같은 마디는 다시 만든다. 새 음형만으로 마디가 꽉 차서 매번 같아지면 새 음형을 하나 덜 넣는다.
- 생성 규칙은 빌드할 때와 테스트에서 모든 단계에 대해 여러 시드로 유효성 검사를 거친다.

### 생성 마디 다듬기

지금 생성기는 박마다 음형을 따로 뽑아서 실제 리듬과 다른 마디가 많이 나온다. 3연음을 배운 뒤 단계(23단계부터)에서 시드 20개로 만든 마디 14,840개를 재 보니 47.9% 가 한 마디 안에 3연음과 8분·16분 음표가 섞여 있었다. 쉼표로 시작하는 박은 1~4박에 거의 같은 비율(4/4 마디 17,160개에서 4463, 4544, 4397, 4281)로 놓였다. 두 마디 사이에 반복 구조도 없다. 아래 규칙을 더한다. 확률 값은 모두 가설이다.

리듬 단위 갈래

| 갈래 | 음형 |
|---|---|
| 기본 | 4분음표, 4분쉼표 |
| 둘로 나눔 | 8분·16분 계열, 8분-4분-8분 당김음, 점4분음표, 점8분음표, 붙임줄, 16분 당김음 |
| 셋으로 나눔 | 3연음 계열, 4분음표 3연음 |

1. 한 마디에 둘로 나눔과 셋으로 나눔을 섞지 않는다. 음형 단계는 새 음형의 갈래를 따르고, 채우기는 같은 갈래와 기본 갈래에서만 고른다. 복습 단계는 마디마다 배운 갈래 하나를 먼저 고르고 그 갈래 음형만 넣는다.
2. 두 마디 단위의 둘째 마디는 60% 확률로 첫 마디를 한두 박만 바꿔 반복하고, 나머지는 새로 만든다. 바꾸는 박은 원래 규칙대로 다시 뽑는다(새 음형 자리는 새 음형, 채우기 자리는 채우기). 2박 음형 자리는 2박을 함께 바꾼다. 바꾼 결과는 첫 마디와 달라야 한다. 도입 마디에는 적용하지 않는다.
3. 쉼표로 시작하는 채우기는 강박에 덜 놓는다. 4/4 에서 1박 0.25, 3박 0.5, 2·4박 1 의 가중치로 자리를 고르고, 3/4 에서는 1박 0.25, 2·3박 1 이다. 새 음형 자리는 지금처럼 고르게 고른다. 새 음형은 어느 박에서든 읽을 수 있어야 하기 때문이다.
4. 두 마디 단위의 마지막 박이 채우기 자리면 50% 확률로 4분음표나 4분쉼표로 끝낸다.

- 마디당 새 음형 수(3부 3개, 4부 4개)는 바꾸지 않는다.
- 둘로 나눔과 셋으로 나눔을 한 마디에서 바꿔 치는 연습은 이 규칙에서 빠지고 "나눔 바꾸기" 섹션이 맡는다.

### 나눔 바꾸기

생성 마디 다듬기 규칙 1 때문에 한 마디 안에서 둘로 나눔과 셋으로 나눔을 바꿔 치는 연습이 없다. 실제 곡에서는 8분음표 뒤에 3연음이 오는 마디가 흔하므로 따로 섹션을 둔다. 16분음표 섹션 복습 다음, 점음표 섹션 앞이다. 3연음과 16분음표를 모두 배운 직후다.

| 단계 | 재료 | 바꾸는 단위 |
|---|---|---|
| 1부 8분과 3연음 | 8분음표 2개, 3연음, 4분음표 | 반 마디(2박)마다. 앞뒤 순서는 무작위 |
| 2부 8분과 3연음 박마다 | 1부와 같음 | 박마다 갈래를 바꾼다 |
| 3부 16분과 3연음 | 16분음표 4개, 3연음, 4분음표 | 반 마디마다 |
| 4부 섞기 | 지금까지 배운 둘로 나눔·셋으로 나눔 1박 음형(쉼표 포함) | 박마다 갈래를 무작위로 고르되 한 마디에 두 갈래가 모두 있어야 함 |

- 4/4 만 쓴다. 도입 마디는 없고 생성 마디 8개, 연습 단위는 두 마디로 다른 단계와 같다.
- 4분음표는 기본 갈래라 어느 쪽 자리에도 들어갈 수 있다. 다만 한 마디에서 둘로 나눔과 셋으로 나눔 음표가 각각 하나 이상 있어야 한다.
- 규칙 2(둘째 마디 부분 반복), 규칙 4(두 마디 끝 마무리)는 그대로 적용한다. 규칙 1(갈래 통일)은 이 섹션에서 적용하지 않는다.
- 단계 id 는 `switch-부`(예 `switch-1`), 진도·기록 키도 이 id 다. 섹션이 끼어들어 뒤 단계 번호는 4씩 밀리지만 id 는 그대로라 기존 진도는 그 단계에 남는다. 이미 뒤 단계를 진행한 사용자는 깨지 않은 첫 단계인 이 섹션부터 다시 보인다.

### 마디 흐름

아래에서 "단위" 는 두 마디다.

| 상황 | 동작 |
|---|---|
| 단위를 처음 쳐서 깔끔함 | 바로 다음 단위로 넘어간다 |
| 한 번이라도 틀린 단위 | 2번 연속 깔끔하면 다음 단위로. 깔끔했지만 아직이면 다음 자리에 "한 번 더" |
| 단위에서 Miss, Extra, 방향 틀림이 나옴 | 그 순간 다시 칠 것으로 정해지고 다음 자리에 같은 단위와 "다시" 를 보여 준다 |
| 단위 끝에 평균 오차가 60ms 를 넘음 | 다시 친다 |
| 마지막 단위 통과 | 단계 통과. 흐름을 멈추고 요약 화면 |
| 건너뛰기 | 지금 단위를 실패로 남기고 다음 단위로 간다. 건너뛴 단위가 있으면 단계는 깬 것으로 치지 않는다 |
| 그만하기 | 흐름을 멈추고 단계 목록으로 |

- 깔끔한 단위의 조건은 자유 연습의 깔끔한 반복과 같다(Miss 0, Extra 0, 방향 틀림 0, 평균 오차 60ms 이하).
- 단위의 경계는 다음 단위 첫 박보다 good 범위(120ms)만큼 앞이다. 그 뒤의 탭은 다음 단위 것으로 본다. 그래서 성공은 경계 시각에, 실패는 틀린 순간에 정해진다.
- 흐름 도중에는 BPM 을 바꾸지 않는다. 자동 템포가 켜져 있으면 단계가 끝난 뒤 단위당 평균 시도 수로 다음 BPM 을 정한다. 1.3번 이하면 올리고 3번을 넘으면 내린다.
- 메트로놈 가이드(매 박, 첫 박만, 한 마디씩 쉬기, 없음)는 단위 안의 마디마다 적용한다. 한 마디씩 쉬기는 단위의 둘째 마디에서 소리를 끈다.
- 듣고 따라 치기 방식에서는 단위를 처음 칠 때만 두 마디를 들려주고 친다. 틀려서 다시 칠 때는 다시 들려주지 않고 바로 친다. 악보 숨기기 설정이 켜져 있으면 다음 단위도 보여 주지 않는다.

### 단계 요약

- 단위별 악보와 시도 횟수, 통과 여부, BPM
- 3번 이상 걸린 단위는 다시 볼 마디로 표시한다.
- 음형 실력 점수는 단계 하나를 한 번 친 것으로 기록한다. 건너뛴 단위가 있으면 0, 단위당 평균 시도 수가 1.5 이하면 1, 그 밖은 0.6.

| 다음 단계 잠금 | 막히면 빠른 연습이나 다른 단계로 갈 수 있어야 함. 대신 앞으로 남은 단계는 흐리게 표시 |
| 단계마다 고정 패턴 4개 (처음 구현) | 몇 번 하면 외워져서 악보를 읽지 않게 됨 |
| 고정 패턴 수만 늘리기 | 외우는 데 시간이 더 걸릴 뿐 결국 외워짐 |
| 도입 없이 전부 무작위 | 처음 배우는 단계에서 새 음형을 따로 익힐 기회가 없음 |
| 마디마다 한 번씩 치고 틀려도 넘어가기 | 틀린 마디를 고칠 기회가 없음 |
| 한 마디 단위 | 사용자 결정으로 두 마디 단위. 한 마디는 너무 짧아 흐름을 읽는 연습이 덜 됨 |
| 틀린 뒤 한 번만 깔끔하면 넘어가기 | 우연히 맞은 것과 익힌 것을 구분하지 못함 |
| 도입 마디를 모든 부에 넣기 | 2부부터는 이미 아는 음형이라 반복이 지루함 |

## 6. 설계

### 데이터

| 개념 | 담는 것 | 어디에 |
|---|---|---|
| 음형 | id, 이름, 박 단위 셀(1박 또는 2박) | 코드 |
| 단계 | 번호, 섹션, 제목, 부, 종류(음형·복습), 음형 id, 생성 사양, 도입 마디 유무 | 코드에서 계산 |
| 단계 흐름 | 이번에 만든 두 마디 단위 목록, 지금 단위 번호, 단위별 시도 결과 | 화면 상태. 저장하지 않음 |
| 단계 진도 | 단계별 처음 깬 시각, 최고 BPM | localStorage `rhythm-lab.stage-progress.v1` |
| 패턴 기록 | 자유 연습 패턴·방식별 최고 별, 최고 클린 BPM, 시도 수 | localStorage `rhythm-lab.records.v1` |

- 단계 목록과 생성 규칙은 앱 배포가 source of truth 다. 진도와 기록은 사용자 기기가 source of truth 이고 앱 업데이트가 덮어쓰지 않는다.
- 단계 id 는 `음형id-부` 와 `review-섹션키-부` 다. 단계를 중간에 끼워 넣거나 섹션 순서를 바꿔도 기존 진도가 다른 단계로 옮겨 붙지 않는다.
- 저장 형식은 바뀌지 않는다. 기존 진도와 기록은 그대로 남는다.

### 다른 기능에 주는 영향

- [[quick-practice]] 의 "이어서" 는 지금 단계의 고정 패턴 대신 새로 만든 패턴을 낸다. 빠른 연습에서 패턴을 통과해도 단계를 깬 것으로 치지 않는다. 단계는 단계 흐름으로만 깬다.
- [[dictation]] 은 단계의 생성 사양으로 문제를 만들기 때문에 영향이 없다.
