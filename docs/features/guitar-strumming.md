# 기타 스트로크

## 1. 배경

배경은 [[design#1. 배경]]과 같다. 기타 스트로크는 타이밍뿐 아니라 다운(↓)·업(↑) 방향, 헛스트로크, 강세까지 맞춰야 한다. 일반 8비트 스트로크에서 손은 8분음표 간격으로 계속 위아래로 움직이고, 표시된 위치에서만 줄을 친다. 헛스트로크 위치에서도 손은 멈추지 않는다.

## 2. 목표

- 사용자는 리듬 악보와 ↓↑ 방향이 표시된 스트로크 패턴을 보고 탭으로 연습할 수 있다.
- 방향 구분 모드에서는 방향 오류와 타이밍 오류가 따로 집계된다.
- 8비트·16비트 패턴과 싱코페이션, 강세 표시를 지원한다.

## 3. 비목표

- 강세 강도 판정. 터치로 측정할 수 없다.
- 실제 기타 소리 입력.

### 실패로 볼 것

- 헛스트로크를 쉼표처럼 취급해서 손 왕복 흐름을 가르치지 못한다.

## 4. 사용자 흐름

1. 연습 탭에서 "기타 스트로크" 를 고른다. 각 패턴 악보 위에 ↓↑ 와 헛스트로크 `(↑)` 가 보인다.
2. 입력 방식(왼쪽 ↓ · 오른쪽 ↑, 방향 없이 탭)을 고르고 패턴을 고른다.
3. 보고 치기면 카운트인 후, 듣고 따라 치기면 한 번 들은 뒤 탭한다. 미리 듣기에서 다운은 낮게, 업은 높게, 강세는 크게 난다.
4. 결과에서 타이밍과 방향 틀림 수, 틀린 자리를 본다.

## 5. 기능 정의

### 입력 방식

| 방식 | 동작 | 판정 | 결정 |
|---|---|---|---|
| 좌우 분리 탭 | 왼쪽(F 키, ↓ 키) 다운, 오른쪽(J 키, ↑ 키) 업 | 타이밍 + 방향 | 기본값 |
| 일반 탭 | 화면 어디나, 아무 키 | 타이밍만 | 제공 |
| 위아래 스와이프 | 실제 동작과 비슷 | 시점·방향 판정이 복잡해 타이밍 측정에 불리 | 보류([[TODOS]]) |

### 패턴

- 슬롯마다 침, 강세로 침, 헛스트로크 중 하나를 적는다. 방향은 슬롯 위치로 정한다. 8비트는 8분 슬롯, 16비트는 16분 슬롯이고 앞 슬롯이 다운, 뒤 슬롯이 업이다. 손은 늘 위아래로 움직이고 표시된 곳에서만 줄을 친다.
- 헛스트로크는 악보에서 쉼표와 괄호 친 화살표로 그린다. 목표 이벤트를 만들지 않으므로 그 자리를 탭하면 Extra 다.
- 10개. 4분 다운, 8비트 다운업, 팝, 포크, 백비트 강세, 당김, 레게 업스트로크, 16비트 다운업, 16비트 펑크, 16비트 록.

### 판정

- 타이밍 매칭은 방향과 상관없이 한다. 맞게 매칭된 탭의 방향이 목표와 다르면 "방향 틀림" 으로 따로 센다.
- 방향 틀림이 있는 반복은 깔끔한 반복이 아니다. 별점에서는 Extra 와 같은 무게로 깎는다.
- 방향 없이 친 탭은 방향을 따지지 않는다.

### 탈락한 후보

| 후보 | 탈락 사유 |
|---|---|
| 스트로크 전용 엔진 | 리듬 엔진의 방향·헛스트로크 속성과 판정의 방향 비교로 충분 |
| 방향이 틀리면 Miss | 타이밍은 맞았는데 Miss 로 세면 무엇을 틀렸는지 알 수 없음 |
| 헛스트로크 탭을 손동작 입력으로 받기 | 손 왕복은 표시로 가르치고, 탭은 소리 나는 곳에만 하는 편이 판정이 명확 |

## 6. 설계

| 개념 | 담는 것 |
|---|---|
| 스트로크 패턴 정의 | id, 이름, 박당 슬롯 수, 슬롯별 기호, 태그 |
| 탭 | 시각, 트랙, 방향(좌우 분리일 때) |
| 판정 hit | 타이밍 오차, 등급, 방향 틀림 여부 |
| 지표 | 기존 지표에 방향 틀림 수 |
