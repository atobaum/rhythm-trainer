# 폴리리듬

## 1. 배경

배경은 [[design#1. 배경]]과 같다. 폴리리듬은 양손에 다른 패턴을 주는 것과 다르다. 같은 시간 구간을 서로 다른 비율로 균등 분할한다. 2:3 이면 같은 시간에 왼손 2번, 오른손 3번을 치고 주기 시작점에서 함께 친다.

## 2. 목표

- 사용자는 2:3, 3:4, 4:5 폴리리듬을 양손으로 연주하고 손별 정확도와 상대 타이밍을 볼 수 있다.
- 사용자 지정 정수 비율을 연습할 수 있다.

## 3. 비목표

- 비정수 비율

### 실패로 볼 것

- 반복할수록 두 손의 목표 시각이 어긋난다(누적 오차).

## 4. 사용자 흐름

1. 연습 탭에서 "폴리리듬" 을 고른다. 2:3, 3:2, 3:4, 4:3, 4:5, 5:4 와 직접 지정한 비율이 두 줄 악보로 보인다(왼손 : 오른손).
2. 비율을 고르거나 직접 지정(1~9)한다. 손을 하나만 골라 따로 칠 수도 있다.
3. 듣고 따라 치기면 두 손 소리를 높낮이로 구별해 한 번 들려준다.
4. 양손으로 연주하고 손별 정확도와 두 손 간격을 본다([[two-hand]]와 같은 화면).

## 5. 기능 정의

- 한 마디(4/4)를 왼손 n, 오른손 m 으로 균등 분할한다. 2의 거듭제곱이 아닌 분할은 잇단음표로 쓴다(3은 2분음표 3연음, 5는 4분음표 5연음).
- 두 손이 함께 치는 곳은 주기 시작점이다. 결과의 "함께 칠 때" 간격이 이것이다.
- 시점은 유리수로 계산하므로 반복해도 오차가 쌓이지 않는다.
- 두 줄 악보는 음 사이 간격을 시간에 비례하게 그려서 어느 손이 먼저인지 보인다.

### 탈락한 후보

| 후보 | 탈락 사유 |
|---|---|
| 공통 분할(2:3 이면 6분할) 소리 가이드 | 기준음과 겹쳐 오히려 헷갈림. 비례 간격 악보로 위치를 보여줌 |
| 2마디 이상 주기 | 1마디 균등 분할로 목표 비율을 모두 표현 |

## 6. 설계

리듬 엔진의 유리수 onset 과 다중 트랙, [[two-hand]]의 입력·판정·결과를 그대로 쓴다.
