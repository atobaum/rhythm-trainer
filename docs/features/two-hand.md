# 양손 독립

## 1. 배경

배경은 [[design#1. 배경]]과 같다. 양손으로 서로 다른 리듬을 동시에 연주하는 능력은 한 손 리듬과 별개로 훈련해야 한다.

## 2. 목표

- 사용자는 왼손·오른손 악보를 보고 화면 좌우를 탭해 두 리듬을 동시에 연주할 수 있다.
- 결과에서 왼손, 오른손, 동시 타격 정확도를 따로 본다.

## 3. 비목표

- 세 트랙 이상

### 실패로 볼 것

- 두 손이 동시에 탭했는데 하나만 기록된다.
- 좌우 탭이 브라우저 제스처(확대 등)로 먹힌다.

## 4. 사용자 흐름

1. 연습 탭에서 "양손" 을 고른다. 각 패턴은 위가 왼손, 아래가 오른손인 두 줄 악보다. 같은 시점의 음표는 세로로 맞춰 그린다.
2. 손(양손, 왼손만, 오른손만)을 고른다. 한 손씩 먼저 익힐 수 있다.
3. 듣고 따라 치기면 왼손은 낮은 소리, 오른손은 높은 소리로 한 번 들려준다.
4. 화면 왼쪽 반(F 키 등 왼쪽 키)은 왼손, 오른쪽 반(J 키 등 오른쪽 키)은 오른손이다.
5. 결과에서 손별 정확도와 두 손을 함께 쳐야 하는 곳의 간격을 본다.

## 5. 기능 정의

- 좌우 입력 영역은 서로 다른 트랙으로 기록한다. 포인터마다 이벤트를 받으므로 두 손가락이 동시에 눌러도 각각 기록된다.
- 손별로 따로 매칭한다. 왼손 탭이 오른손 음표에 붙지 않는다.
- 타이밍 트랙과 결과의 반복별 줄을 손마다 나눈다(L1, R1).
- 손별 지표와 함께 "함께 칠 때 두 손 간격 평균" 을 보여준다. 같은 반복의 같은 시점에서 두 손이 모두 맞힌 곳만 센다. 둘 다 30ms 늦었어도 동시에 쳤다면 간격은 작다.
- 패턴 11개를 쉬운 순서로 둔다. 한 손이 4분음표로 박을 지키고 다른 손이 8분, 뒷박, 쉼표, 당김음, 16분, 3연음을 치는 것부터 두 손이 엇갈리는 것, 펑크까지.

### 탈락한 후보

| 후보 | 탈락 사유 |
|---|---|
| 왼손만 → 오른손만 → 결합을 강제하는 단계 | 손 선택으로 원할 때 나눠 칠 수 있으면 충분 |
| 손 구분 없이 한 트랙으로 판정 | 어느 손이 틀렸는지 알 수 없음 |

## 6. 설계

| 개념 | 담는 것 |
|---|---|
| 양손 패턴 | 역할 left·right 두 트랙 |
| 한 손 연습 | 고른 손의 트랙만 남긴 단일 트랙 패턴 |
| 입력 영역 | 이름, 트랙, 키 목록 |
| 손별 결과 | 트랙별 지표, 함께 친 쌍 수와 평균 간격 |
