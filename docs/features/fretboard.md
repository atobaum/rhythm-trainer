# 지판 외우기

## 1. 배경

기타 지판에서 어느 줄 몇 프렛이 무슨 음인지 바로 떠올리지 못한다. 코드 모양과 탭 악보로만 쳐 왔기 때문이다. 음 위치를 모르면 코드 구성음을 찾거나 멜로디를 다른 위치로 옮겨 치기 어렵다. 기타 없이 폰만으로 짬날 때 위치와 음 이름의 대응을 반복해서 외우고 싶다.

리듬 연습과 같은 앱의 별도 연습으로 둔다. 근거는 [[decisions]] 2026-11-10 design 행에 있다.

## 2. 목표

- 사용자는 첫 화면에서 지판 외우기로 바꿔 설정 없이 기본 범위로 바로 시작할 수 있다. 처음 방식은 음 보고 위치 찍기다.
- 사용자는 지판에 찍힌 점을 보고 그 위치의 음 이름을 12개 버튼 중에서 고른다(위치 보고 음 맞히기).
- 사용자는 줄 번호와 음 이름을 보고 그 줄에서 해당 위치를 찍는다(음 보고 위치 찍기).
- 사용자는 답하는 즉시 정답인지 보고, 틀리면 정답을 본다.
- 사용자는 연습할 줄(1~6번줄 중 여러 개)과 프렛 범위(시작~끝)를 고를 수 있고, 다음에 열면 그 설정이 남아 있다.
- 사용자는 세션이 끝나면 정답 수, 평균 응답 시간, 틀린 문제 목록을 본다.

## 3. 비목표

- 음 소리 재생. 1단계에서는 보고 외우기만 한다. 소리는 써 본 뒤 TODOS 에서 검토한다.
- 실제 기타 소리로 답하기(마이크 인식). [[design#3. 비목표]]
- 위치별 정답률 기록, 약한 위치를 더 자주 내는 출제. 1단계 이후로 미룬다.
- 표준 튜닝 외 튜닝, 7현·베이스, 왼손잡이 반전.
- 스케일, 코드 구성음, 음정 연습. 음 위치 하나를 외우는 데 집중한다.
- 제한 시간, 점수 경쟁. 응답 시간은 보여 주기만 한다.
- 사실적인 지판 그림(나무 결, 프렛 간격 비율). 위치를 구분하는 데 필요 없다.

### 실패로 볼 것

- 폰에서 의도한 칸 옆 칸이 찍힌다.
- 같은 위치가 연달아 나오거나, 고른 범위 밖 위치가 나온다.
- 지판 그림에서 몇 번줄 몇 프렛인지 세어야 알 수 있다(인레이 점과 프렛 번호로 바로 알 수 있어야 함).

## 4. 사용자 흐름

1. 첫 화면 위쪽의 "리듬 / 지판" 전환에서 지판을 고른다. 지판 첫 화면에 방식, 줄, 프렛 범위, 문제 수와 시작 버튼이 보인다. 처음에는 기본값이 채워져 있다.
2. 시작을 누르면 첫 문제가 나온다. 카운트인은 없다.
3. 위치 보고 음 맞히기는 지판의 한 칸에 점이 찍히고 아래에 음 이름 버튼 12개가 있다. 버튼을 누르면 답이다.
4. 음 보고 위치 찍기는 지판 위에 "3번줄 A" 처럼 문제가 나오고 해당 줄이 강조된다. 그 줄의 칸을 찍으면 답이다.
5. 맞으면 초록으로 표시하고 0.5초 뒤 다음 문제로 간다. 틀리면 고른 답을 빨강, 정답을 초록으로 표시하고 1.5초 뒤 다음 문제로 간다.
6. 정한 문제 수를 다 풀면 결과 화면에 정답 수/전체, 평균 응답 시간, 틀린 문제 목록이 보인다. 다시 하기와 처음으로 가기가 있다.
7. 세션 중 언제든 그만두기로 처음 화면으로 돌아갈 수 있다. 그만둔 세션은 결과를 보여 주지 않는다.

## 5. 기능 정의

### 지판 그림

| 항목 | 규칙 |
|---|---|
| 방향 | 가로. 헤드(개방현)가 왼쪽, 1번줄이 위, 6번줄이 아래 |
| 그리는 프렛 | 고른 프렛 범위에 양쪽으로 한 칸씩 여유를 더해 그린다. 여유 칸은 0프렛과 15프렛 밖으로 넘지 않는다. 예) 5~8 을 고르면 4~9 를 그린다. 그리는 범위가 0프렛을 포함하면 맨 왼쪽에 개방현 칸과 너트(굵은 세로선)를 그린다 |
| 프렛 간격 | 모든 칸 같은 폭. 화면 폭을 그리는 칸 수로 나눈다 |
| 줄 굵기 | 1번줄이 가장 가늘고 6번줄이 가장 굵다. 1번줄 1px 에서 6번줄 4px 까지 고르게 늘린다 |
| 인레이 | 3, 5, 7, 9, 15프렛에 점 하나, 12프렛에 점 둘. 줄 사이 가운데에 지판 바탕과 구분되는 진한 색으로 그린다. 지판 아래 가장자리 밖(프렛 번호 위)에도 같은 프렛에 작은 사이드 점을 찍는다. 12프렛은 사이드 점도 둘 |
| 표시 글자 | 지판 아래 프렛 번호, 왼쪽에 줄 번호와 개방현 음(E B G D A E) |
| 범위 밖 칸 | 고르지 않은 줄과 여유 칸은 옅게 표시하고 찍어도 반응하지 않는다. 문제로도 나오지 않는다 |

- 폰 세로 화면에서 기본 범위 0~12프렛을 고르면 여유 칸을 더해 0~13프렛 14칸을 그리고 칸 폭이 약 23px 다(390px 폭 화면에서 22.7px 로 확인). 터치 판정은 칸 전체(줄 사이 가운데부터 다음 줄 사이 가운데까지)를 쓴다. 칸이 좁다고 느끼면 범위를 좁히거나 가로 화면으로 쓴다.

### 음 이름

- 영문 표기. 답 버튼은 C, C♯/D♭, D, D♯/E♭, E, F, F♯/G♭, G, G♯/A♭, A, A♯/B♭, B 의 12개다.
- 문제로 음 이름을 보여 줄 때도 변화음은 `C♯/D♭` 처럼 둘 다 쓴다.
- 위치의 음은 표준 튜닝(6번줄부터 E A D G B E)의 개방현 음에서 프렛 수만큼 반음 올린 음이다. 옥타브는 구분하지 않는다.

### 연습 범위

| 설정 | 선택지 | 기본값 |
|---|---|---|
| 방식 | 위치 보고 음 맞히기, 음 보고 위치 찍기 | 음 보고 위치 찍기 |
| 줄 | 1~6번줄 중 1개 이상 | 전부 |
| 프렛 범위 | 시작 0~15, 끝 0~15, 시작 ≤ 끝 | 0~12 |
| 문제 수 | 10, 20, 40 | 20 |

- 설정은 기기에 저장하고 다음에 열면 그대로 쓴다.
- 줄을 하나도 고르지 않으면 시작 버튼을 비활성화한다.

### 출제

- 위치 보고 음 맞히기는 고른 줄 × 고른 프렛의 모든 위치 중 하나를 고르게 뽑는다.
- 음 보고 위치 찍기는 고른 줄 중 하나를 고르게 뽑고, 그 줄의 범위 안에 있는 음 중 하나를 고르게 뽑는다. 위치가 아니라 음을 기준으로 뽑아서 범위 안에 두 번 나오는 음이 더 자주 나오지 않게 한다.
- 바로 앞 문제와 같은 문제는 다시 뽑는다. 가능한 문제가 하나뿐이면 그대로 낸다.

### 판정

- 위치 보고 음 맞히기는 고른 버튼의 음이 그 위치의 음이면 정답이다.
- 음 보고 위치 찍기는 문제의 줄에서 그 음인 칸을 찍으면 정답이다. 범위 안에 그런 칸이 두 곳이면 어느 쪽이든 정답이고, 틀렸을 때는 두 곳 모두 초록으로 보여 준다.
- 음 보고 위치 찍기에서 문제의 줄이 아닌 칸을 찍으면 반응하지 않는다. 오답으로 세지 않는다.
- 문제마다 한 번만 답한다. 답한 뒤 다음 문제로 넘어가기 전까지의 입력은 무시한다.
- 응답 시간은 문제가 화면에 나온 시각부터 답한 입력의 이벤트 시각까지다.

### 결과

| 항목 | 내용 |
|---|---|
| 정답 수 | 정답 수 / 전체 문제 수 |
| 평균 응답 시간 | 정답 문제만 평균, 초 단위 소수 첫째 자리 |
| 틀린 문제 | 문제마다 줄, 프렛, 정답 음, 사용자가 고른 답 |

- 결과는 저장하지 않는다. 위치별 기록은 1단계 범위 밖이다.

### 숫자 설정값

다음은 설정값으로 두고 써 보며 조정한다. 정답 후 다음 문제까지 0.5초, 오답 후 다음 문제까지 1.5초, 줄 굵기 1~4px.

### 탈락한 후보

| 후보 | 탈락 사유 |
|---|---|
| 별도 레포로 만들기 | PWA, 저장, 배포를 다시 깔아야 함 |
| 도레미 표기 | 코드 표기와 이름이 달라 실제 연주에 바로 쓰기 어려움 |
| 샵·플랫 버튼 따로 두기(17개) | 같은 음을 두 버튼 중 골라야 해서 지판과 무관한 오답이 생김 |
| 같은 음이 두 곳이면 모두 찍어야 정답 | 한 문제가 길어지고 위치 하나를 빨리 떠올리는 목적과 다름 |
| 세로 지판 | 터치하기는 좋지만 탭 악보와 방향이 달라 사용자가 가로를 고름 |
| 항상 0~12프렛을 그리고 범위 밖을 옅게 | 범위를 좁혀도 칸이 넓어지지 않아 폰 세로 화면에서 찍기 어려움 |
| 고른 범위만 정확히 그리기 | 범위 끝 칸이 지판 가장자리에 붙어 주변 위치와 비교할 기준이 없음 |
| 오답 후 "다음" 버튼으로 넘어가기 | 매 오답마다 한 번 더 눌러야 해서 흐름이 끊김 |
| 시간 제한 | 처음 외울 때 압박만 늘고 응답 시간 표시로 충분 |

## 6. 설계

- 지판 규칙(위치의 음, 출제, 판정)은 React 에 의존하지 않는 순수 함수로 둔다. 무작위는 주입받아 테스트에서 고정한다.
- 지판 그림은 SVG 로 그린다. 악보 렌더러와 오디오 엔진은 쓰지 않는다.
- 설정은 기존 설정과 별도 키로 localStorage 에 저장한다. 읽기에 실패하거나 값이 범위를 벗어나면 기본값으로 시작한다.
- 리듬 연습의 상태, 기록, 커리큘럼 진도는 읽지도 쓰지도 않는다.
