# PWA(오프라인) 계획

[[design#4. 사용자와 사용 상황]]의 "네트워크가 없어도 연습할 수 있어야 한다. 최초 설치 후 오프라인 동작." 을 맞춘다. 앱 아이콘도 기본 템플릿 아이콘에서 앱 아이콘으로 바꾼다.

## 설계

| 파일 | 책임 |
|---|---|
| `vite.config.ts` | `vite-plugin-pwa` 의 generateSW. manifest(이름, 아이콘, standalone, 세로, 테마색 `#2563eb`), 빌드 결과 전체 precache. 악보 폰트가 번들에 들어가 파일 한도를 4MB 로 올림 |
| `public/favicon.svg` | 파란 둥근 사각형에 8분음표 두 개를 잇는 빔. 브라우저 탭 아이콘 |
| `public/pwa-192x192.png`, `pwa-512x512.png`, `maskable-512x512.png`, `apple-touch-icon.png` | 설치 아이콘. maskable 과 애플 아이콘은 모서리 없는 꽉 찬 배경 |
| `index.html` | 상대 경로 아이콘(`./favicon.svg`), apple-touch-icon, theme-color |

- 새 버전은 서비스 워커가 백그라운드에서 받고, 페이지를 다시 열 때 적용된다. 연습 중 강제 새로고침은 하지 않는다.
- 기록은 localStorage 라 서비스 워커와 무관하게 유지된다.

## Tasks

| # | 내용 | 검증 |
|---|---|---|
| 1 | 아이콘, manifest, 서비스 워커 | `pnpm build && pnpm test && pnpm lint`. `dist` 를 `/rhythm-trainer/` 하위 경로로 서빙해 서비스 워커 활성, precache 목록 확인. 서버를 끈 뒤 새로고침해 단계 목록과 악보가 보이는지 확인 |
| 2 | 휴대폰 설치 | 배포본을 홈 화면에 추가해 아이콘과 전체 화면 실행, 비행기 모드에서 연습 시작 |
