# 노래에 맞춰 치기 구현 계획

[[songs]]를 구현한다.

## 코드 수준 설계

| 모듈 | 책임 |
|---|---|
| `src/domain/songs/songs.ts` | 곡 데이터. 곡마다 id(`song-작은별` 대신 영문 `song-twinkle` 등), 제목, 출처, 박자, 기본 BPM, 음 목록(음높이 이름 `C4` 또는 쉼표, 길이 분수, 붙임줄). 직접 받아 적는다 |
| `src/domain/songs/song-pattern.ts` | 곡 → 두 마디 단위 `RhythmPattern` 목록(단일 트랙, 붙임줄은 기존 tie 표현), 그리고 단위별 멜로디 음(시작 위치, 길이, 주파수) |
| `src/domain/songs/songs.test.ts` | 모든 곡의 마디 길이가 박자와 맞음, 마디 수가 짝수, 패턴 변환이 유효, 음높이 이름이 유효 |
| `src/application/practice-types.ts`, `src/infrastructure/audio/audio-engine.ts` | `SoundKind` 에 `melody` 추가, `ScheduledSound` 에 선택 필드 `frequency`, `durationMs`. 멜로디 음색은 sine·triangle 계열로 기준음·탭 소리와 구별되게 |
| `src/application/bar-flow-plan.ts`, `src/domain/practice/bar-flow.ts` | "실패해도 다음 단위로" 옵션(continuous). 칸 결과는 기록하되 다시 치지 않음. 단위 소리에 멜로디 소리를 함께 예약 |
| `src/presentation/pages/StageFlowScreen.tsx` | 노래 모드 표시(제목, 진행), 연습 중 자동 조절 끔, 끝나면 노래 결과로 |
| `src/presentation/pages/SetupScreen.tsx`, `pattern-lists.ts` | 목록 종류에 "노래". 곡 목록 행(제목, 출처, 박자, 마디 수, 최고 별점) |
| `src/presentation/pages/PracticeApp.tsx`, `ResultScreen.tsx` | 노래 시작(곡 기본 BPM, 읽기 방식 고정), 끝나면 곡 전체 판정으로 결과 화면과 기록 저장(`practice-records`), 자동 템포 미적용 |

- 곡 데이터를 받아 적을 때 음높이·리듬을 원곡 악보 기억과 대조해 한 번 더 검토한다. 확신이 없는 곡은 빼고 문서 곡 목록에서도 뺀다.
