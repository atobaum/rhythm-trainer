# 나눔 바꾸기 단계 구현 계획

[[curriculum#나눔 바꾸기]]를 구현한다.

## 코드 수준 설계

| 모듈 | 책임 |
|---|---|
| `src/domain/rhythm/generator.ts` | 생성 사양에 "갈래 바꾸기" 옵션을 더한다. 값은 `half`(반 마디마다 갈래 교대, 순서 무작위), `beat`(박마다 교대), `mixed`(박마다 무작위, 한 마디에 두 갈래 모두). 옵션이 있으면 규칙 1(갈래 통일)을 끄고, 박마다 정해진 갈래의 음형(+ 기본 갈래 4분음표)에서 고른다. 한 마디에 두 갈래 음표가 각각 하나 이상 있는지 확인하고 아니면 다시 뽑는다. 규칙 2·4 는 유지하되 변형 결과도 같은 조건을 지켜야 한다 |
| `src/domain/curriculum/stages.ts` | PLAN 에 16분음표 복습 뒤 `switch` 섹션을 넣는다. 새 항목 종류(음형도 복습도 아닌 "바꾸기")로 단계 4개, id `switch-1`~`switch-4`, 도입 마디 없음, 4/4, 생성 8마디. 아이콘은 8분 2개 + 3연음 같은 대표 셀 |
| `src/domain/curriculum/stages.test.ts` | 114단계, 섹션 위치, 시드 20개로 바꾸기 단계의 모든 마디에 두 갈래가 있음, 1·3부 반 마디 단위, 2부 박마다 교대, 나머지 단계 섞인 마디 0개 유지 |

- 단계 수에 의존하는 다른 테스트·문서(110 → 114)가 있으면 함께 고친다. 빠른 연습 큐레이션과 청음은 단계 사양을 쓰므로 새 단계가 자연히 들어간다. 깨지는 곳이 있으면 고친다.
