# 단계 도입 마디와 마디 흐름 구현 계획

[[curriculum#7.2 2단계 도입 마디와 마디 흐름]]을 구현한다. 단계의 고정 패턴 4개를 없애고, 시작할 때 만든 마디들을 끊지 않고 한 마디씩 친다.

## 코드 수준 설계

| 모듈 | 책임 |
|---|---|
| `src/domain/curriculum/stages.ts` | 단계에 도입 마디 유무와 부별 마디당 새 음형 수를 둔다. 고정 패턴 목록 함수(`stagePatterns`)를 없애고, 시드를 받아 도입 마디와 생성 마디를 한 마디짜리 패턴 목록으로 돌려주는 함수를 둔다. 빠른 연습용 패턴 생성 사양(1~2마디)은 그대로 둔다 |
| `src/domain/practice/bar-flow.ts` | 마디 흐름 상태(마디 목록, 지금 마디, 마디별 시도 수, 건너뜀)와 진행 규칙(통과, 다시, 건너뛰기, 끝남), 단계 실력 점수, 끝난 뒤 템포 |
| `src/application/bar-flow-plan.ts` | 시간 칸 계획. 한 칸은 한 마디 길이다. 보고 치기는 모든 칸이 치기 칸, 듣고 따라 치기는 듣기 칸과 치기 칸이 번갈아 온다. 칸별 메트로놈 소리, 칸에 놓인 마디의 목표 이벤트, 칸 경계(다음 칸 시작 − good 범위) |
| `src/application/bar-flow-evaluation.ts` | 한 치기 칸의 판정. 경계 전 탭만 쓰고, 지금 시각까지 확정된 Miss·Extra·방향 틀림이 있으면 바로 실패, 경계를 지나면 깔끔한 반복 조건으로 성공·실패 |
| `src/presentation/pages/StageFlowScreen.tsx` | 지금 마디와 다음 마디(흐림, 실패 시 "다시"), 타이밍 트랙, 탭 영역. 칸이 정해질 때 듣기 칸의 음표 소리를 예약한다 |
| `src/presentation/pages/PracticeApp.tsx` | 단계 시작은 단계 흐름 화면으로, 끝나면 단계 진도·실력 점수·자동 템포를 반영하고 요약 화면 |
| `src/presentation/pages/SummaryScreen.tsx` | 마디별 시도 횟수와 다시 볼 마디 표시 |
| `src/domain/curriculum/quick-curation.ts` | "이어서" 를 새로 만든 패턴으로. 빠른 연습에서 단계 깨기 제거 |

- 메트로놈 소리는 마디 내용과 무관해서 지금처럼 몇 칸 앞까지 미리 예약한다. 듣기 칸의 음표 소리만 칸 내용이 정해지는 순간 예약한다. 늦어도 칸 시작 120ms 전에 정해진다.
- 한 단계의 마디는 박자표가 모두 같아서 칸 길이가 일정하다.

## Tasks

| # | 내용 | 검증 |
|---|---|---|
| 1 | 단계 마디 생성(도입 규칙, 부별 새 음형 수, 시드마다 다른 마디, 앞 마디와 같으면 다시 만들기) | 단위 테스트(모든 단계 × 여러 시드 유효성, 새 음형 수, 도입 마디 예시), Chrome 에서 전 단계 마디 렌더링 |
| 2 | 마디 흐름 상태와 진행 규칙, 칸 계획, 칸 판정 | 단위 테스트(깔끔하면 다음, 중간 Miss 즉시 실패, 경계 뒤 탭은 다음 칸, 건너뛰기, 끝남, 점수·템포) |
| 3 | 단계 흐름 화면(보고 치기)과 연결, 단계 요약 | Chrome 에서 키 입력으로 통과·실패·다시·건너뛰기·끝까지 |
| 4 | 듣고 따라 치기 흐름, 자동 템포, 메트로놈 가이드 | Chrome 에서 듣기·치기 번갈아, 실패 시 다시 듣기, 끝난 뒤 BPM 변화 |
| 5 | 빠른 연습 영향 반영, 휴대폰 폭 화면, 문서(사용법, quick-practice, 완료 기준) | 단위 테스트, Chrome 390 폭 프레임 |

각 task 마다 `pnpm build && pnpm test && pnpm lint` 를 통과시키고 커밋한다.
