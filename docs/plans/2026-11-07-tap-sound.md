# 탭 소리 구현 계획

[[practice-screen#7.3 3단계 탭 소리]]를 구현한다.

## 코드 수준 설계

| 모듈 | 책임 |
|---|---|
| `src/application/practice-types.ts` | 소리 종류에 양손용 낮은·높은 탭 소리를 더한다 |
| `src/infrastructure/audio/audio-engine.ts` | 새 소리의 음색. 세션과 무관하게 지금 바로 소리 하나를 내는 함수. 세션 정지에 끊기지 않게 세션 출력이 아닌 기본 출력에 연결한다 |
| `src/presentation/tap-zones.ts` | 입력 영역에서 탭 소리 종류를 고르는 함수 |
| `src/presentation/practice-settings.ts` | 탭 소리 켜기 설정, 기본 켜짐 |
| `src/presentation/pages/SetupScreen.tsx` | 설정 탭에 켜기·끄기 |
| `src/presentation/pages/SessionScreen.tsx`, `StageFlowScreen.tsx` | 포인터·키 입력마다 설정이 켜져 있으면 탭 소리. 판정 시각 필터와 무관하게 낸다 |

- 지연 보정 화면(`CalibrationScreen.tsx`)은 바꾸지 않는다.
