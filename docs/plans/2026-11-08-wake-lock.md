# 화면 꺼짐 방지 구현 계획

[[practice-screen#화면 꺼짐 방지]]를 구현한다.

## 코드 수준 설계

| 모듈 | 책임 |
|---|---|
| `src/presentation/hooks/use-wake-lock.ts` | `active` 인자가 참인 동안 `navigator.wakeLock.request('screen')` 을 유지한다. `visibilitychange` 로 화면이 다시 보이면 다시 요청한다. 거짓이 되거나 언마운트되면 `release()`. API 가 없거나 요청이 실패하면 조용히 넘어간다 |
| `src/presentation/pages/PracticeApp.tsx` | 화면 종류가 연습(패턴 반복), 단계 흐름, 청음, 노래일 때 `useWakeLock(true)` |
