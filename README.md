# Rhythm Lab

악보를 보고, 리듬을 듣고, 화면을 탭해 재현하면서 리듬 읽기·모방·청음·양손 독립·폴리리듬을 훈련하는 모바일 우선 웹앱.

## 설치

Node.js 20+ 와 pnpm 이 필요하다.

```bash
pnpm install
```

## 사용법

```bash
pnpm dev     # http://localhost:5173
pnpm test    # vitest
pnpm build   # tsc -b + vite build
pnpm lint    # oxlint
```

휴대폰에서 쓰려면 `pnpm dev --host` 로 띄우고 같은 Wi-Fi 에서 표시된 주소로 연다.

배포본은 https://atobaum.github.io/rhythm-trainer/ 에 있다. `main` 에 합치면 GitHub Actions 가 빌드해 GitHub Pages 에 올린다.

### 화면

- 연습 탭 맨 위 **빠른 연습**의 시작을 누르면 진도, 약한 음형, 처음 보는 패턴, 도전 문제를 섞어 정한 시간만큼 연습한다. 시간과 문제 구성은 설정 탭에서 바꾼다.
- **방식**
  - 보고 치기. 한 마디 카운트인 후 악보를 보고 탭한다.
  - 듣고 따라 치기. 한 번 듣고 바로 탭한다. "악보 숨기고 기억해서 치기" 를 켤 수 있다.
  - 듣고 맞히기. 리듬을 듣고 악보 4개 중 고르거나 박마다 음형을 채운다. 단계 목록에서 범위를 고른다.
- **템포와 기준음**. 자동을 켜면 패턴 사이에 빨리 통과하면 +5, 오래 걸리거나 건너뛰면 −5 BPM. 기준음은 매 박, 첫 박만, 1마디씩 끄기, 끔.
- **대상**
  - 단계. 음형별 110단계. 시작하면 마디 8개(음형 1부는 새 음형만 따로 치는 도입 2마디를 더해 10개)를 새로 만들어 끊지 않고 두 마디씩 친다. 지금 두 마디 아래에 다음 두 마디가 흐리게 보인다. 통과 규칙은 아래 패턴과 같다. 마지막 두 마디까지 건너뛰지 않고 통과하면 단계를 깬다. 듣고 따라 치기는 처음 칠 때만 들려준다.
  - 고정 패턴, 기타 스트로크, 양손, 폴리리듬 목록. 스트로크는 왼쪽 ↓ 오른쪽 ↑ 로 친다. 양손·폴리리듬은 왼쪽이 왼손, 오른쪽이 오른손이고 한 손만 고를 수 있다. 폴리리듬은 비율을 직접 지정할 수 있다.
- 패턴은 처음에 바로 깔끔하게(Miss·Extra·방향 틀림 0, 평균 오차 60ms 이하) 치면 통과한다. 한 번이라도 틀렸으면 2번 연속 깔끔하게 칠 때까지 끊김 없이 반복한다. 건너뛸 수 있다.
- 결과 화면에서 별점, 음표별 치우침, 내 연주와 정답 다시 듣기를 본다.
- 설정 탭의 **지연 보정**은 틱에 맞춰 20번 탭해 기기 지연을 잰다. 이어폰을 바꾸면 다시 잰다.

### 키보드

| 대상 | 키 |
|---|---|
| 한 손 패턴 | 아무 키 |
| 스트로크 | F·D·S·A·← ↓ 는 다운, J·K·L·→ ↑ 는 업 |
| 양손·폴리리듬 | 왼쪽 키(F 등)는 왼손, 오른쪽 키(J 등)는 오른손 |
| 공통 | Esc 는 그만하기 |

### 저장되는 것

기록은 그 브라우저의 localStorage 에만 있다. 키는 `rhythm-lab.settings.v1`, `rhythm-lab.stage-progress.v1`, `rhythm-lab.records.v1`, `rhythm-lab.skills.v1`, `rhythm-lab.activity.v1`.
